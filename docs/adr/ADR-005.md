# ADR-005: WebSockets invalidate caches instead of owning state

Status: accepted

## Context

Connections drop and messages can repeat or arrive late.

## Decision

REST and PostgreSQL remain authoritative. Authenticated event subscriptions invalidate TanStack Query caches; subscribing after reconnect triggers refetch.

## Consequences

No replicated client state machine, STOMP, or broker. Revoked memberships and expired sessions lose subscriptions.
