# ADR-007: Interval-based availability representation

Status: accepted

## Context

Cell-per-row storage scales with display granularity rather than meaningful availability.

## Decision

Persist canonical merged intervals. Translate each interval into a range of legal 30-minute start positions and accumulate difference arrays.

## Consequences

Normalization has sorting cost. Scoring canonical intervals and finding the top three is O(A + S); benchmarks exclude database and normalization time.
