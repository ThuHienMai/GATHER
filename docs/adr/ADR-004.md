# ADR-004: Transactional outbox for side effects

Status: accepted

## Context

A process can crash after a mutation commits but before notifications are sent.

## Decision

Insert an immutable outbox payload in the mutation transaction. Claim records with SKIP LOCKED and deduplicate delivery rows. Send Telegram HTTP outside transactions with fenced leases.

## Consequences

WebSocket invalidations can repeat. An ambiguous Telegram send can be delivered twice; exactly-once external delivery is not promised.
